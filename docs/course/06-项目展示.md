# 星河工坊

团队项目档案与协作展示网站

互联网数据库开发 / 项目展示 / 2026-10-19

PHP + Yii2 + MySQL / 前台展示、后台维护、留言审核、可还原课程交付

DEMO01、DEMO02、DEMO03 为演示成员占位编号，不是真实学号；以下分工为建议方案，不是实际贡献证明。

@page
## 01 · 为什么做这个项目
团队成果、成员能力和访客交流分散在不同工具中；我们把它们连成一个可浏览、可维护、可恢复的数据库应用。
@diagram
成员与技能 -> 项目与动态 -> 访客了解团队
访客留言 -> 管理员审核 / 回复 -> 形成公开交流
@end
核心交付：完整前后台 + 十张以上业务表 + 统计图形 + 六项 PDF 下载 + 安装 SQL + 一键部署与还原。

@page
## 02 · 架构与数据库价值
@diagram
浏览器 -> PHP / Yii2 MVC -> MySQL / InnoDB
公共展示与留言 -> 后台身份与审核 -> 事务、约束与审计
@end
14 张表表达真实业务：成员与技能、项目与成员为多对多关联；项目与里程碑、留言与回复为一对多；身份与展示资料分离，登录尝试与审计独立维护。
使用框架认证、输入验证、输出转义和 CSRF 防护；不把隐藏按钮当成权限，不自造认证协议。具体字典见设计文档。

## 03 · 现场演示脚本
| 时间建议 | 操作 | 观察重点 |
| 0:00 - 1:00 | 首页、成员、项目与动态 | 数据库内容和公共导航；展示图形。 |
| 1:00 - 2:00 | 访客提交唯一留言 | 提交成功但未审核不公开。 |
| 2:00 - 3:00 | 管理员批准并回复 | 同一数据闭环，刷新访客窗口可见。 |
| 3:00 - 4:00 | 编辑项目并退出 | 前台同步变更；退出后后台受保护。 |
| 4:00 - 5:00 | 下载 PDF、介绍备份还原 | 六项材料可读；新卷恢复核对业务状态。 |

## 07 · 可复现与收尾
一条启动命令：python scripts/dev.py up
备份：python scripts/dev.py export --path .cache/exports/team-backup.sql
独立恢复：切换 Compose 项目名与端口，在空数据库执行显式确认导入，再验证登录、编辑和留言。
已执行：6 个真实 HTTP 场景、14 表还原逐行一致、Chromium 151 桌面及 390px 移动端操作录屏；浏览器运行零错误。验证边界与复现命令见 docs/validation/application.md。
提交前人工事项：替换真实身份与文件名、确认 MVC 贡献与真实分工、补充团队记录；现有 WebM 为无声自动操作，仍需补真人讲解并联系助教、确认当年截止时间。
谢谢观看。欢迎从用户旅程而不是页面数量来审阅这个系统。

# 星河工坊 · 需求文档

互联网数据库开发 / 团队项目档案与协作展示网站

版本：1.0 / 2026-10-19 / 本地演示交付

成员标识：DEMO01、DEMO02、DEMO03 为演示占位编号，不是真实学号。正式提交前须替换姓名、学号、分工确认和所有文件名；不得将本示例分工作为实际个人贡献证明。

## 1. 问题与目标
课程团队需要一个统一入口展示成员能力、项目成果与协作记录。分散在聊天记录和个人文件夹中的信息难以检索，访客留言也缺乏审核和回复。本项目用一个可本地还原的数据库网站闭合“展示 - 互动 - 管理 - 发布 - 备份”的用户旅程。
交付重点不是云平台规模，而是前后台真实读写同一业务数据库、超过十张有业务意义的表，以及能够重新安装、演示和恢复的课程材料。

## 2. 角色与权限边界
| 角色 | 目标 | 允许行为与限制 |
| 访客 | 了解团队并交流 | 浏览已发布成员、项目、动态；提交待审核留言；下载公开课程文档。不能访问后台修改内容。 |
| 成员 | 更新团队成果 | 登录后编辑授权资料与内容；不能仅通过修改 URL 获得管理员权限。 |
| 管理员 | 维护与审核 | 管理团队、成员、项目、动态及留言；审核后才向前台公开访客内容。 |

## 3. 功能需求与验收
| 编号 | 功能 | 可观察的验收结果 |
| F01 | 团队与成员展示 | 首页能看到团队介绍；成员入口展示简介、技能和关联项目；中文正常显示。 |
| F02 | 项目与动态 | 前台可浏览项目和发布动态；后台修改并提交后，刷新对应前台可观察到结果。 |
| F03 | 访客留言 | 无需登录可提交合法留言；页面明确显示待审核，不把提交成功误作公开发布。 |
| F04 | 审核与回复 | 管理员审核留言；只有审核通过记录出现在公开列表；回复关联原留言。 |
| F05 | 后台认证 | 演示管理员能登录；错误密码不能登录；退出后不能继续访问受保护页面。 |
| F06 | 内容维护 | 表单验证必填、长度与关联对象；非法输入不会使数据库进入半完成状态。 |
| F07 | 图形展示 | 统计图形读取真实业务计数；空数据时保留清楚的零值，不将示例静态图冒充实时统计。 |
| F08 | 作业下载 | 页面列出六项作业；点击返回 PDF，文件名遵循课程约定，下载内容可正常阅读。 |
| F09 | 安装与恢复 | 新数据库能自动安装演示数据；导出后能在独立空数据库恢复，并重走登录和留言旅程。 |

## 4. 数据需求
共 14 张表覆盖团队、成员、用户身份、技能、成员技能、项目、项目成员、动态、留言、回复、里程碑、作业下载、审计与登录尝试。多对多关联使用独立关系表，而不是逗号拼接字符串。业务表及字段以设计文档自动导出的数据库字典和 data/schema.sql 为准；data/install.sql 是从实际演示数据库导出的同结构还原文件。
公开展示数据与登录凭据分离；密码保存单向哈希（Password Hash），不保存可读明文。访客姓名和留言是个人数据，正式提交前应去除真实访客内容；种子数据只用于演示。

## 5. 非功能需求
安全：服务端验证、输出转义、参数化数据库查询；写操作使用 POST 并启用跨站请求伪造防护（Cross-Site Request Forgery, CSRF）。隐藏后台菜单不等于授权。
兼容性：以桌面和移动端现代浏览器为目标，使用服务端渲染（Server-Side Rendering, SSR）而非依赖单页应用。保持现有 Python 初始化、Compose 启停与备份命令接口。
可维护性：遵循模型-视图-控制器（Model-View-Controller, MVC）分层；业务约束在模型和数据库表达，视图负责呈现；PHP 文件具备英文注释头。
部署边界：默认仅绑定 127.0.0.1，MySQL 不发布宿主端口；这是课程本地演示配置，不是公网生产部署方案。容器重建后临时会话失效，需要重新登录。
性能：典型课程数据量下浏览、表单、图形均可交互使用；对列表使用明确排序和合理数量限制，不承诺未经测量的吞吐量。

## 6. 协作与范围控制
版本控制指定 Git，托管可使用 GitHub；项目管理指定仓库任务看板与 docs/course 中的交付清单。分工建议与实际完成记录分离；真实成员应保留自己的任务、评审和提交记录。
范围内：本地团队网站、后台内容维护、审核留言、图形统计、SQL 及六份提交物。范围外：在线支付、开放注册、文件上传、富文本编辑、分布式部署、云付费资源。新增功能不得牺牲核心用户旅程。

## 7. 完成与提交门槛
代码、SQL、PDF 三者描述一致；演示使用独立浏览器会话扮演访客与管理员；验证重建和恢复后数据不丢失。已有无声自动操作录屏，最后仍需真实成员确认 MVC 贡献，替换占位学号，补充口头讲解并联系助教演示。

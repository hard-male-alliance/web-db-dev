# 星河工坊 · 实现文档

面向可运行课程交付的实现说明

版本：1.0 / 2026-10-19 / DEMO01、DEMO02、DEMO03 为演示编号，不构成真实贡献声明。

## 1. 实现路径与产物
项目从可复现 PHP/Yii2/MySQL 环境出发，增加团队网站业务模型、公共页面与后台管理，再补齐课程 SQL 和六项文档。既有 Python 环境管理与容器持久化契约保持不变，避免业务上线破坏初始化和备份流程。
实现结果应以当前代码和可执行验收为准；本说明不虚构真实团队开发会议、看板截图或个人 Git 提交历史。实际贡献需要由真实成员结合 Git 日志与评审记录补充确认。

## 2. 项目目录与职责
| 路径 | 内容 | 维护边界 |
| common/ | 共享模型与配置 | 业务字段、关联、验证与数据库连接。 |
| frontend/ | 公共控制器、视图与入口 | 团队成员展示、项目动态、留言、统计和下载。 |
| backend/ | 管理控制器、视图 | 登录、权限检查、编辑发布与留言审核。 |
| data/schema.sql | 安全初始化基线 | 数据表、关系、约束及演示种子；重复启动不重置现有记录。 |
| data/install.sql | 实际 mysqldump 导出 | 从独立空白演示库导出；含 DROP TABLE，仅用于明确的还原操作。 |
| data/team/ | 六项正式格式 PDF | 页面提供下载，文件名中的演示编号须人工替换。 |
| docs/course/ | 可编辑交付源文档 | 数据字典在构建时从 SQL 提取，避免重复维护。 |
| scripts/ 与 infra/ | 初始化、检查与运维 | Python 统一入口，容器内数据库导出导入。 |
| tests/ | 自动化验证 | 应覆盖 HTTP 用户旅程、权限边界与数据库约束。 |

## 3. 关键实现机制
公共站点从数据库取回团队、成员、项目与动态，通过 PHP 视图渲染。公共内容不信任数据库中的字符串：来自种子、后台还是访客的数据都应在输出处转义。
后台先执行身份和授权检查，再进入表单校验和持久化。密码验证使用 Yii2 Security，而不是将用户输入与明文密码直接比较。浏览器提供的角色和成员编号不作为授权事实。
留言创建默认进入待审核状态；前台查询只选择允许公开的状态。管理员审核或回复后再重定向，避免刷新重复请求。关联关系由数据库约束兜底，而不是只靠前端下拉框。
PDF 生成脚本 scripts/build_submissions.py 读取六份 UTF-8 源文档，生成中文 PDF；本次构建嵌入 TrueType 中文字体。设计文档字典直接解析 data/schema.sql。单一数据源（Single Source of Truth）减少表结构与文档漂移。data/install.sql 则是实际 MySQL 导出，用于满足 SQL 导出提交要求，不能拿它做每次启动的初始化。

## 5. 实施与验证方法
先运行 python scripts/dev.py up，确认数据库初始化和页面就绪，再使用浏览器分别扮演访客、成员、管理员。覆盖登录失败与成功、内容编辑、未审核留言不可见、审核后可见、回复、下载与退出。
真实数据库测试应检查唯一键、外键、回滚、中文表情及业务状态；端到端（End-to-End, E2E）测试应通过 HTTP 和 Cookie 操作实际应用，而非仅调用控制器内部方法。
恢复验证必须在独立数据库上完成：创建业务记录、导出、恢复到新卷、重新登录并核对内容；不能只证明 SQL 文件存在。验证结果及未覆盖平台以仓库验证记录为准，不在文档中承诺未经运行的测试结论。

## 6. Git 与项目管理证据采集
正式团队可使用 git log --oneline --decorate 与 git log --numstat 查看实际提交；保留对应任务编号、验收条件和评审记录。提交数不是贡献质量的替代指标，合并提交和自动生成 PDF 也不应重复计入个人业务开发量。
建议看板列：待做、进行中、待评审、已验收。每张卡片写明功能、负责人、涉及表、MVC 文件与验收旅程。作业 PDF 中若补截图，必须来自真实工具，不使用合成截图冒充完成证据。

## 7. 已执行验证与录屏
Windows 项目内 PHP 8.4.26、Yii 2.0.55 和实际 MySQL 8.4.11 环境的 HTTP 验收完成 6 个场景（最终扩展运行 8.479 秒），覆盖真实 Cookie、CSRF、登录退出、成员权限、编辑发布、审核回复和六项 PDF 下载。测试包含进度 0 / 100 合法、越界与非整数非法、中文表情长度、未公开内容隔离等边界。
独立还原验证对 14 张表逐行比较，内容、关联、凭据及审计均与源库一致。该结果不等同于在恢复库重新运行浏览器测试；当前完整容器镜像也未在本机 Docker 引擎上执行。详细证据与限制见 docs/validation/application.md。
Playwright / Chromium 151 的真实浏览器自动录屏已生成 data/team/星河工坊_操作演示.webm（约 2.4 MB），复现脚本为 scripts/record_walkthrough.cjs。旅程包括个人资料保存、发布动态、访客待审核留言、审核回复及下载，同时检查桌面与 390 像素移动端；该次录屏没有浏览器错误。

# 星河工坊 · 用户手册

访客、成员与管理员的操作指南

版本：1.0 / 2026-10-19 / 课程演示版

## 1. 打开网站
先按照部署文档启动，在浏览器打开 http://127.0.0.1:8080/。如果配置了 APP_PORT，用实际端口替换 8080。无需安装浏览器插件。
首页展示团队简介和网站导航。站点中的成员姓名、项目与记录为演示资料；DEMO01、DEMO02、DEMO03 不是真实学号。

## 2. 访客：浏览与下载
1. 从首页进入成员列表，查看各成员的个人简介与技能；项目页可以查看关联成员与成果。
2. 进入项目和动态入口，浏览已公开内容；页面中显示的统计对应业务数据库，而非外部追踪平台。
3. 进入课程作业下载入口，选择需求、设计、实现、用户手册、部署或项目展示。浏览器会打开或下载 PDF，可另存到本地。
4. 若下载失败，先确认应用已经重建且 data/team 中有六份 PDF；不要修改下载地址来读取其他服务器文件。

## 3. 访客：留下消息
1. 打开留言入口，填写姓名、联系方式（若表单提供）和留言正文。不要填写密码、身份证号或其他敏感信息。
2. 提交后检查成功提示。新留言需要审核，因此“提交成功”不代表所有人立即可见。
3. 如有字段错误，按页面提示修改后重试；不要连续点击提交。
4. 审核通过后刷新留言页查看公开记录及管理员回复；被拒绝的留言不会出现在公共页面。

## 4. 登录后台
打开 /admin 或页面的后台入口。以下凭据仅限本地课程演示：
| 账户 | 密码 | 使用说明 |
| admin | admin123456 | 管理员，可维护内容、审核和回复留言。 |
| member | member123456 | 成员账户，仅操作授权范围，不能代替管理员审核。 |
登录后通过后台菜单操作。若登录失败，检查大小写和数据库是否已初始化。不要把演示密码复用于个人账户；不要将本地服务暴露到公网。

## 5. 后台：编辑与发布
1. 选择需要维护的团队、成员、项目或动态内容。
2. 点击编辑或新建，填写表单必填项；保持关联对象有效。
3. 点击保存后查看提示。保存失败时根据错误信息修正，不要假定修改已生效。
4. 新开访客窗口刷新相应页面，确认展示内容及公开状态符合预期。
5. 成员账户若看到禁止访问或权限不足，不应通过直接修改地址绕过限制，应联系管理员。

## 6. 管理员：审核与回复
1. 打开留言管理，定位待审核留言，核实不含隐私或不合适内容。
2. 选择批准或拒绝。批准后在未登录浏览器窗口验证可见，拒绝后确认不可见。
3. 在对应留言下添加回复。核对回复归属，不要把敏感内部信息写入公开回复。
4. 操作完成点击退出。关闭标签页不一定销毁登录状态；共享电脑必须主动退出。

## 7. 常见问题
| 现象 | 原因方向 | 处理步骤 |
| 页面无法打开 | Docker 未启动或端口冲突 | 运行 python scripts/dev.py logs；确认容器健康，检查 APP_PORT。 |
| HTTP 503 / 数据库不可用 | MySQL 尚未就绪或连接配置不一致 | 等待就绪并查看日志；不要清空卷来解决普通连接问题。 |
| 表单提示验证失败 | 缺失字段、长度超限、无效关联 | 按提示修改后再提交，保留原输入以便核对。 |
| 更新后页面未变化 | 应用源码被复制进镜像或内容未公开 | 重新构建容器；确认保存成功、审核状态和浏览器刷新。 |
| 重建后退出登录 | 会话保存在临时目录 | 重新登录即可；数据库业务记录应仍存在。 |
| 留言暂时不可见 | 处于待审核或拒绝状态 | 等待管理员审核，不重复提交同一内容。 |
| 修改 .env 密码后连接失败 | 既有卷中的 MySQL 用户未同步更改 | 恢复原配置或按数据库流程修改账户；更改初始化变量不会自动轮换密码。 |

## 8. 数据安全与支持
正常停止使用 python scripts/dev.py down，业务数据保留。不要运行 docker compose down --volumes，除非明确要永久删除且已备份。
报告问题时提供页面地址、操作步骤、错误文本与时间；不要提供密码、Cookie 或含个人信息的完整数据库。备份、还原和恢复演示见部署文档。
